# 😊 AI-Based Sentiment Analysis System

## 📌 Overview

The **AI-Based Sentiment Analysis System** is a Natural Language Processing (NLP) application that analyzes text and identifies its sentiment as **Positive, Negative, or Neutral**.

The project is developed using Python and can be easily executed in **Google Colab**.

## 🚀 Features

- Analyze user-provided text
- Detect Positive, Negative, and Neutral sentiment
- Calculate sentiment score
- Analyze multiple sentences
- Display results in a table
- Generate sentiment visualization
- Interactive text-based interface

## 🛠️ Technologies Used

- Python
- Natural Language Processing (NLP)
- NLTK
- VADER Sentiment Analysis
- Pandas
- Matplotlib
- Google Colab

## 🔄 Working Process

```text
User Input
    ↓
Text Processing
    ↓
VADER Sentiment Analyzer
    ↓
Sentiment Score
    ↓
Positive / Negative / Neutral
    ↓
Result & Visualization
```

## ▶️ How to Run

1. Open **Google Colab**.
2. Create a new notebook.
3. Copy the project code into the notebook cells.
4. Run the installation cell.
5. Run the remaining cells.
6. Enter a sentence when prompted.
7. View the predicted sentiment and score.

## 💡 Example

**Input:**
```text
I really love this application!
```

**Output:**
```text
Sentiment: Positive
Sentiment Score: 0.6696
```

Another example:

```text
Input: The service was terrible.

Sentiment: Negative
```

## 📊 Sentiment Categories

| Sentiment | Description |
|---|---|
| Positive | Indicates a positive opinion or emotion |
| Negative | Indicates a negative opinion or emotion |
| Neutral | Indicates a neutral or unclear opinion |
